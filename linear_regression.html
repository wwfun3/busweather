先用一句話理解 1. Understand in One Sentence

「Linear Regression（線性回歸）就是：根據已知資料，找出一條『最能描述資料趨勢的直線』，再用這條直線預測新的數值。」 "Linear Regression means: finding a straight line that 'best captures the trend of historical data', and using this line to predict new numerical values."

生活實例： REAL-WORLD EXAMPLE:

我知道一些「樓價」和「實用面積」的成交資料，能不能讓電腦學習出一條規律，然後預測一個從未在資料庫出現過的 500 呎單位大概值多少錢？ Given historical records of "Property Prices" and "Floor Areas", can we train a computer to discover the underlying mathematical pattern, and forecast what an unseen 500 sq ft apartment is worth?

答案就是：交給 Linear Regression（線性回歸）！ The answer is: Linear Regression!

Linear Regression 到底在「學」什麼？ 3. What is Linear Regression Actually "Learning"?

很多初學者會誤以為：「Machine Learning 就是把資料放進黑盒子，電腦自己變出答案。」 Many beginners assume: "Machine Learning is a magical black box where the computer spontaneously invents answers."

其實更精確地說：模型正在學習 Parameters（參數）。 More precisely: The model is learning Parameters.

Linear Regression 的數學公式可以寫成： The mathematical equation for Linear Regression is formulated as:

$$\hat{y} = b_0 + b_1 x$$

公式拆解成白話文： Deconstructing the formula into plain English:

符號Symbol 專業名稱Technical Term 白話意思Intuitive Meaning
\(x\) Feature 輸入資料（例如：讀書時間、單位面積） Input feature / explanatory variable (e.g. study hours, floor area)
\(y\) Actual Value 真實答案（例如：真實考獲的分數、歷史成交價） Ground truth label (e.g. actual exam score, recorded transaction price)
\(\hat{y}\) Prediction 模型根據直線公式計算出的預測結果（唸作 y-hat） Predicted value produced by the model (pronounced "y-hat")
\(b_0\) Intercept 直線在 Y 軸的起點（當 \(x=0\) 時的預測值） The Y-axis baseline intercept (prediction when \(x=0\))
\(b_1\) Slope / Coefficient \(x\) 每增加 1 單位時，\(y\) 大約改變多少幅度 Rate of change: expected change in \(y\) for every 1-unit increase in \(x\)
👉 所以電腦「學習」的實質目標，就是在海量可能中尋找一組最完美的 \(b_0\) 與 \(b_1\)！ 👉 Therefore, the computer's practical learning goal is to discover the optimal set of \(b_0\) and \(b_1\)!

但問題來了：哪一條直線才是「最好」？ 5. But Which Line is the "Best"?

假設我們在坐標系上有 100 個資料點。世界上有無窮無盡條穿梭其中的直線——有的向上偏，有的向下偏，有的斜率極陡，究竟憑什麼決定哪一條是唯一最佳？ Suppose we have 100 data points plotted in space. Infinite lines could cut across them — tilted up, tilted down, steep or shallow. How do we objectively define which single line is the best?

Least Squares Method（最小平方法） Least Squares Method

最小平方法的核心哲學極度樸實無華：
「讓所有資料點的『預測錯誤』加起來，盡可能達到全宇宙最小。」 The philosophy of Least Squares is delightfully straightforward:
"Minimize the total aggregate prediction error across all data points."

6

什麼叫 Prediction Error（預測誤差 / 殘差）？ 6. What is Prediction Error (Residual)?

假設某位學生真實考了 \(y = 70\) 分，但直線模型預測他考 \(\hat{y} = 65\) 分，那麼： Suppose a student actually scored \(y = 70\), but the model estimated \(\hat{y} = 65\):

$$\text{Error} = y - \hat{y} = 70 - 65 = +5$$

這個誤差在統計學上有個標準名稱：Residual（殘差）。
在幾何圖形上，殘差就是真實資料點與回歸直線上預測點之間的垂直距離。 In statistics and machine learning, this error is called the Residual.
Geometrically, the residual is the vertical distance between the actual data point and the prediction on the line.

真實點 ● (y = 70) │ │ ← Residual 垂直殘差距離 (y - ŷ = +5) │ ○ 模型在該 X 的預測位置 (ŷ = 65) ─────────────────────────────── Regression Line (回歸直線)
Actual Point ● (y = 70) │ │ ← Residual (Vertical distance: y - ŷ = +5) │ ○ Model prediction at this X (ŷ = 65) ────────────────────────────────────────── Regression Line

為什麼不直接把 Error 加起來？ 7. Why Not Just Sum Up the Errors Directly?

這是一個關鍵洞見。讓我們看一個極端案例： This is a crucial insight. Consider this extreme scenario:

資料點Data Point 真實誤差 (Error)Actual Error 直接相加Direct Sum 誤差平方 (\(\text{Error}^2\))Squared Error (\(\text{Error}^2\))
點 APoint A+10\(10 - 10 + 5 - 5 = 0\) !
正負相抵！Canceled out!		\(10^2 = 100\)
點 BPoint B-10\((-10)^2 = 100\)
點 CPoint C+5\(5^2 = 25\)
點 DPoint D-5\((-5)^2 = 25\)
總計：Total: 總和 = 0（荒謬假象！）Sum = 0 (Deceptive illusion!) SSE = 250

⚠️ 如果直接相加，總和是 0！電腦會天真地以為「這條直線神準、完全沒有錯」，但事實上每一點都錯得離譜。所以我們要將 Error 平方，確保負數不與正數互相抵消！ ⚠️ If we sum them directly, the total is 0! The computer would falsely assume the line is flawlessly accurate, when in reality every prediction is completely off. By squaring each error, negative values cannot cancel out positive values!

8

Least Squares 的核心公式 8. The Least Squares Core Formula

因此，Linear Regression 的神聖使命，就是找出讓以下數值達到全域最小的直線： Therefore, Linear Regression's explicit objective is finding the line that reaches the global minimum for:

Sum of Squared Errors (SSE) / 殘差平方和
$$\sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

白話解釋：把每一筆點的「真實值與預測值的差距」平方後全部加起來，然後命令電腦找出使這個總和最小的 \(b_0\) 與 \(b_1\)。 Plain explanation: Compute the error for each observation, square them, sum them all, and solve for parameters \(b_0, b_1\) that minimize this total.

一個 Feature 與多個 Features 12. Single Feature vs Multiple Features

先前的例子只有一個 \(x = \text{面積}\)，這叫 Simple Linear Regression（簡單線性回歸）。 Our earlier example had one variable \(x = \text{Area}\), known as Simple Linear Regression.

但真實世界中，一間住宅的價格往往同時受到面積、房間數、樓層、距地鐵站距離、樓齡、景觀等全方位影響： In the real world, housing prices depend simultaneously on area, bedroom count, floor level, transit distance, age, and view:

$$\hat{y} = b_0 + b_1 x_1 + b_2 x_2 + b_3 x_3 + \dots + b_n x_n$$
例如：\(\text{Price} = b_0 + b_1(\text{面積}) + b_2(\text{樓齡}) + b_3(\text{地鐵距離})\) e.g., \(\text{Price} = b_0 + b_1(\text{Area}) + b_2(\text{Age}) + b_3(\text{Transit})\)
這就稱為 Multiple Linear Regression（多元線性回歸）。幾何上它不再只是一條 2D 直線，而是在高維度空間中尋找一張「最佳擬合超平面 (Hyperplane)」！ This is termed Multiple Linear Regression. Geometrically, it extends from a 2D line into finding an optimal fitting "Hyperplane" in multidimensional space!
13

「Linear」究竟是什麼意思？ 13. What Does "Linear" Actually Mean?

常見誤解： Common Misconception: 初學者常以為「Linear 代表真實資料必須乖乖、完美地排成一條筆直的線」。 Beginners often believe "Linear means real-world data points must align in a perfectly straight line."

真相是：「Linear」代表的是模型的結構假設——模型假設輸入變數與輸出變數之間的關係可以用固定變化率（恆定斜率）來逼近近似。
當 \(x\) 增加 1，\(y\) 的期望增長量始終是 \(b_1\)，這就是線性關係的本質。 The Truth: "Linear" refers to the model's functional assumption — assuming variables relate with a constant rate of change (constant slope).
When \(x\) increases by 1 unit, the expected increment in \(y\) is strictly \(b_1\).

總結串連：最關鍵的 7 個機器學習名詞 15. Summary: Top 7 Essential Machine Learning Terms

如果你剛踏入機器學習大門，別被複雜符號嚇倒，先牢牢記住這 7 個黃金詞彙： If you are starting your journey in Machine Learning, anchor your understanding around these 7 foundational terms:

01 / FEATURE 特徵 Input Signal

Feature

最簡單理解：輸入資料 (\(x\))。我們拿來當作線索的依據，例如住宅面積、讀書時長。 Plain meaning: Input variable (\(x\)). Signals used as clues, such as floor area or study time.

02 / TARGET 目標值 / 真實標籤 Ground Truth

Target

最簡單理解：真實答案 (\(y\))。歷史資料中已經發生的真實結果（例如真實成交價 6.0M）。 Plain meaning: Ground truth label (\(y\)). The historical outcome we desire to predict (e.g. sales price $6.0M).

03 / PREDICTION 預測值 Forecast

Prediction

最簡單理解：模型猜測的答案 (\(\hat{y}\))。把特徵代入公式後算出來的數值。 Plain meaning: The model's estimated outcome (\(\hat{y}\)), computed by plugging features into the equation.

04 / PARAMETER 參數 Weights

Parameter

最簡單理解：模型需要自行學習調整的數字（\(b_0, b_1\)）。決定了直線的高低與斜率。 Plain meaning: Internal coefficients (\(b_0, b_1\)) learned by the model, setting intercept and slope.

05 / RESIDUAL 殘差 Single Error

Residual

最簡單理解：真實值與預測值的差 (\(y - \hat{y}\))。代表「單筆資料猜錯了多少」。 Plain meaning: Gap between truth and prediction (\(y - \hat{y}\)). Represents error on one point.

06 / LOSS 損失 / 誤差總量 Total Error

Loss

最簡單理解：衡量模型整體「錯得有多嚴重」的綜合指標（例如平方誤差總和 SSE）。 Plain meaning: Metric summarizing how inaccurate the model is overall across the entire dataset (e.g. SSE).

07 / TRAINING 訓練優化 Optimization

Training

最簡單理解：電腦透過演算法不斷調校參數，讓 Loss 達到最小的整個「修練優化過程」。 Plain meaning: The iterative tuning process where optimization algorithms adjust parameters to minimize Loss.

🎓 一句話終極歸納Core Takeaway

Linear Regression = 找出一條最適合歷史資料的直線，使整體預測誤差平方和盡可能小，然後用這條線預測未來新資料。 Linear Regression = Finding the straight line best fitting historical data by minimizing the sum of squared errors, then leveraging that line to forecast future data.

真正理解機器學習的關鍵，不是死記公式，而是參透這條貫穿始終的思維鏈： True comprehension is not about memorizing symbols, but mastering this interconnected cognitive pipeline:

Data ➔ Model ➔ Prediction ➔ Error ➔ Loss ➔ Adjust Parameters ➔ Optimal Model 🚀
