Gradient Descent
梯度下降法

先掌握整個流程

梯度下降不是一次猜中答案，而是用梯度資訊逐步改善參數，令損失通常朝下降方向移動。

STEP 01輸入訓練資料
STEP 02模型作出預測
STEP 03計算損失 Loss
STEP 04計算梯度 Gradient
STEP 05更新參數並重複
⛰

損失 = 山的高度

Loss Function 量度模型預測與真實答案的差距。最佳化的目標通常是降低這個數值。

∇

梯度 = 上坡方向

梯度指向局部上升最快的方向。梯度下降使用它的反方向來更新參數。

👣

學習率 = 步長

學習率決定每次更新的幅度。太小可能很慢，太大可能震盪甚至發散。

一句話記憶： 新參數 = 舊參數 − 學習率 × 梯度。
在合適條件下，這會令損失下降；對所有複雜模型則不保證每一步都下降，也不保證找到全域最低點。

它用在哪裏？

線性回歸、邏輯回歸、神經網絡和許多深度學習模型，都可以使用梯度資訊來最佳化可訓練參數。

VISUAL INTUITION

在濃霧中走下山谷

你看不到整座山，只能觀察腳下附近的斜度。每次走一小步後，再重新判斷方向。

對應模型目前的參數，例如線性模型中的權重 w 和偏置 b。

② 判斷下坡方向

計算損失對參數的導數或梯度。梯度指出上升最快的局部方向。

乘上學習率，決定參數更新幅度；不是每次都跳到遙遠的地方。

重新計算梯度和損失，持續更新，並觀察是否收斂及能否泛化至新資料。

FOUNDATIONS

五個核心概念

了解每一項，就能讀懂梯度下降的更新公式。

1. 參數 Parameters

ŷ = wx + b

w 是權重，決定輸入特徵的影響；b 是偏置，調整預測基準。訓練會更新這些參數。

2. 損失函數 Loss Function

J(w,b) = 1/n Σ(ŷᵢ − yᵢ)²

MSE（均方誤差）常用於回歸。n 是樣本數、ŷᵢ 是預測、yᵢ 是真實值。分類任務常用交叉熵。

3. 導數與梯度

單一參數的導數 dJ/dw 表示損失在該位置的瞬時變化率。多個參數的梯度是偏導數組成的向量。

∇J = [ ∂J/∂w, ∂J/∂b ]ᵀ

梯度是局部上升最快方向；負梯度提供局部下降方向。

4. 學習率 Learning Rate

常以 α 表示，是控制更新步長的超參數。過小會令訓練緩慢，過大可能越過谷底、震盪或發散。

實際合適值取決於損失曲率、梯度尺度、模型與資料。

5. 迭代 Iteration

一次參數更新稱為一次 iteration。訓練集完整使用一次通常稱為一個 epoch。每個 epoch 可包含多次更新。

收斂 Convergence：參數或損失逐漸穩定，但不一定代表全域最佳解。

一個簡單例子

真實答案是 3，模型預測是 0，平方誤差為 9。模型調整權重後預測若變成 2.5，平方誤差就降為 0.25。

梯度下降利用梯度資訊，有系統地尋找能降低損失的參數。

THE MATHEMATICS

公式拆解

不用害怕公式：把它看成「目前值減去一個由斜度和步長決定的修正量」。

θt+1 = θt − α ∇J(θt)
符號意思直覺
θₜ目前參數你現在站的位置
J(θ)損失函數地勢高度
∇J梯度局部上坡最快方向
α學習率每一步的大小
−反方向更新沿局部下坡方向走

導數為正

wnew = w − α(+)

若學習率為正，更新會減少參數 w。對典型向右上升的曲線，這有助向左下坡。

導數為負

wnew = w − α(−)

減去負數等於加上正數，更新會增加參數 w。在該位置向右可能降低損失。

注意： 正負號只告訴你局部更新方向。參數改變與損失改變的關係，仍取決於損失函數本身；步長太大時，損失未必每一步都下降。

WORKED EXAMPLE

逐步手算：從 0 接近 3

一筆資料：x = 1、真實答案 y = 3，模型 ŷ = wx，初始權重 w = 0。

第一步：定義損失

J(w) = (w − 3)²

當 w = 0，預測值為 0，平方誤差為 (0 − 3)² = 9。

第二步：求導

dJ/dw = 2(w − 3)

代入 w = 0，得到梯度 −6。梯度為負，更新公式中的減號會令權重增加。

第三步：更新

wnew = 0 − 0.1 × (−6) = 0.6

更新後損失為 (0.6 − 3)² = 5.76，比原本的 9 小。

反覆更新的數值

迭代舊權重 w梯度新權重新損失
觀察： 權重逐漸接近 3，損失逐漸下降。通常不需要損失恰好等於零；會按收斂準則、驗證表現及計算成本決定何時停止。
DATA STRATEGIES

三種梯度下降方法

主要差別在於：每次更新用多少筆訓練資料估算梯度。

▦

Batch Gradient Descent

每次更新使用整個訓練集計算梯度。

優點：梯度通常較穩定。

限制：資料集很大時，每次更新成本高。

全量資料較穩定
⚡

Stochastic Gradient Descent

典型定義下，每次更新使用一個樣本估算梯度。

優點：單次更新成本低。

限制：梯度波動大，損失可能起伏。

單樣本波動較大
▤

Mini-batch Gradient Descent

每次使用一小批樣本，例如 32、64 或 128 筆。

優點：兼顧運算效率與梯度穩定性，深度學習中非常常見。

小批次常見做法

例子：訓練集有 10,000 筆資料

Batch10,0001
SGD110,000

假設每個 epoch 完整處理資料、沒有丟棄最後不足一批的樣本。SGD 一詞在不同語境也可能泛指隨機最佳化家族；深度學習軟件中的 SGD 通常是具體最佳化器名稱。

相關訓練用語

Iteration：一次參數更新。 Batch：一批訓練樣本。 Epoch：整個訓練集被使用一次。 Convergence：損失或參數逐漸穩定。

PRACTICAL OPTIMIZATION

常見陷阱與改良方法

梯度下降是強大工具，但不是保證每次都找到全域最佳解的魔法。

⚠ 學習率過小

更新幅度有限，損失下降可能很慢。可以觀察曲線，嘗試合理的學習率或排程。

⚠ 學習率過大

可能越過最低點、反覆震盪，甚至令損失發散。應降低學習率或使用適當的排程。

⚠ 特徵尺度差異太大

例如面積以平方呎、距離以米、價格以百萬元表示。適當標準化或縮放特徵，通常有助改善最佳化條件。

⚠ 局部最低點、鞍點、平坦區

非凸損失可能包含多個局部低點、鞍點或梯度很小的區域。初始化與最佳化器設定會影響結果。

⚠ 只看訓練損失

訓練損失降低不保證新資料表現更好。應監察驗證集，留意過度擬合（Overfitting）。

✓ 合理停止條件

可依梯度門檻、損失改善幅度、最大迭代數，或驗證表現不再改善（Early Stopping）決定何時停止。

常見最佳化器比較

方法核心想法常見作用
Momentum累積過去梯度的動量在某些情況下減少震盪、加速一致方向的移動
RMSProp利用梯度平方的移動平均調整有效步長讓不同參數有不同的有效更新尺度
Adam結合一階與二階動量估計，並作偏差修正廣泛用於深度學習，通常有不錯的起始表現

沒有任何一種最佳化器在所有模型與資料集上都必定最佳。對可微凸函數，在合適條件下梯度下降可收斂至全域最低點；一般非凸問題則沒有此保證。

梯度下降與反向傳播：不要混淆

反向傳播 Backpropagation

使用鏈式法則，高效率地計算神經網絡損失對各參數的梯度。

梯度下降／最佳化器

取得梯度後，依更新規則修改參數。它們是合作關係，不是同一件事。

CODE IT YOURSELF

Python：親手執行梯度下降

以下程式只使用 Python 內置功能。可複製到 Google Colab 執行。

零額外套件
# Gradient Descent 梯度下降法
# 目標：找出令 J(w) = (w - 3) ** 2 最小的 w

w = 0.0
learning_rate = 0.1
max_iterations = 100

for step in range(max_iterations):
    # 1. 計算目前的損失
    loss = (w - 3) ** 2

    # 2. 計算目前的梯度
    gradient = 2 * (w - 3)

    # 3. 每隔 10 次顯示一次結果
    if step % 10 == 0:
        print(
            f"Step: {step:3d} | "
            f"w: {w:.6f} | "
            f"Loss: {loss:.6f} | "
            f"Gradient: {gradient:.6f}"
        )

    # 4. 梯度非常小時停止
    if abs(gradient) < 1e-6:
        print("梯度已接近零，停止更新。")
        break

    # 5. 更新權重
    w = w - learning_rate * gradient

print(f"\\n最終權重 w = {w:.6f}")
print(f"最終損失 J(w) = {(w - 3) ** 2:.8f}")
程式的核心只有一行：w = w - learning_rate * gradient

逐行解讀

w = 0.0：設定初始權重。

loss = (w - 3) ** 2：計算錯誤。

gradient = 2 * (w - 3)：計算導數。

abs(gradient) < 1e-6：檢查梯度是否足夠小。

w = w - learning_rate * gradient：更新權重。

把它連到真實模型

真實模型會有多個參數和多筆樣本。以線性回歸為例：

ŷ = w₁x₁ + w₂x₂ + b

需要計算每個參數的偏導數，再分別更新。神經網絡則常用反向傳播或自動微分來求梯度。
